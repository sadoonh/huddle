Application rules

An internal tool catalog, not a marketing page. Favor utility, contrast, and restrained motion.

01 / CONTRAST

White + teal on Charcoal

Use Signal Teal for the logo x on charcoal, but use darker Action Teal for links and controls on white.

02 / SURFACES

Neutral first

Use the cool off-white canvas and white cards. Charcoal belongs in the header, not behind every tool card.

03 / MOVEMENT

Purposeful motion

Retain gentle card lifts and subtle focus states. Support reduced-motion settings. No unnecessary hero or category tabs.
